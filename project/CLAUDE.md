## 開発の流れ

個人共通ルール (`~/.claude/CLAUDE.md`) に加えて、このプロジェクトでは次のループで進める。

1. **開発ループ**: 実装 → `/review-loop` (検証 → code-review → 修正を指摘が出なくなるまで → PR 前のテスト) → 敵対的レビュー (回すかはユーザーに聞く) → push / PR
2. **検証ループ**: 回の始めから作業ツリーが変わった状態で応答を終えようとすると、Stop フックが `.claude/verify.sh` を走らせる。失敗したら直す。1 回の中で 3 回続けて失敗して直せないときは、失敗している検査と残っている問題をユーザーに報告して終える
3. **振り返りループ**: 観点に無い指摘と、レビュー後に見つかったバグは `/retro` で `.claude/review/checklist.md` などに還元する。不具合の修正では、`/review-loop` がレビューの見逃しかを確かめて `/retro` に回す
4. **レビューコメント対応ループ**: PR にコメントが付いたら `/address-comments` で、直す → `/review-loop` → 返信の下書き → OK を取って push と返信
