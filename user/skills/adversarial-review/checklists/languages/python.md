# Python の観点

拡張子 `.py`、shebang が `#!/usr/bin/env python3` のファイルに当てる。データの変換や、小さな運用スクリプトを想定している。

### PY-01 round() と丸めの上限
- 観点: `round()` は偶数丸め (`round(0.5) == 0`、`round(2.5) == 2`) で、上限で頭打ちにならない。「1 日の割合」「0 以上 1 未満」の値に `round(x * 86400)` を使うと、23:59:30 以降が 86400 (= 24:00) になる。時刻、割合、添字の変換で、端の値が範囲の外に出ないか
- 確かめ方: 範囲の端の直前の値 (86399.6 / 86400 など) と、ちょうど .5 の値で変換する

### PY-02 csv.DictReader の欠けた列と余った列
- 観点: 行が短いと、足りない列は `None`、長いと余りは `None` キー (`restkey`) に入る。`row["x"].strip()` が `AttributeError` になる、または、列の欠けを見逃す。ヘッダの順序と名前を検査しているか。文字コード (UTF-8 の BOM、Shift_JIS) と、改行の違い
- 確かめ方: 列が 1 つ少ない行、1 つ多い行、BOM つきのファイルで読む

### PY-03 外から来た文字列をパスにするとき
- 観点: 取得した JSON やファイル名 (manifest の `url` など) を、そのままパスに結合していないか。`..`、絶対パス、区切り文字で、出力先の外に書かないか。許可する形を正規表現で固定しているか
- 確かめ方: `../x`、`/etc/x`、`a/../../x` を入れて、書き込み先を見る

### PY-04 時刻と日付
- 観点: `datetime.now()` と `date.today()` は端末の時刻帯。特定の地域の日付 (営業日、締め日など) を扱うときは、時刻帯を明示する (`ZoneInfo("Asia/Tokyo")` など)。テストが「今日」に依存して、年が変わると壊れないか (日付を引数で渡す)
- 確かめ方: テストの日付を、年末と年始に動かして通るか見る

### PY-05 標準ライブラリのネットワーク呼び出し
- 観点: `urllib.request.urlopen` にタイムアウトがあるか。一時的な失敗 (名前が引けない、タイムアウト) と、恒久的な失敗 (404、403) を区別して、再試行するのは前者だけか。HTTP のエラーコードを `HTTPError` で受けるとき、`URLError` の例外 (サブクラス) の順序を間違えていないか。条件付きの GET (`If-None-Match`) で、手元にファイルが無いときに 304 を返されて詰まらないか
- 確かめ方: ローカルの HTTP サーバー (`http.server`) で、404、304、遅延、接続拒否を作って試す

### PY-06 コマンドの実行と外から来る文字列
- 観点: `subprocess` に `shell=True` と文字列の連結を渡していないか。外から来る値 (ファイル名、引数) が `;`、空白、`-` 始まりで別の操作や別のオプションにならないか。引数はリストで渡し、`-` 始まりのファイル名は `--` の後ろに置く。`os.system` と `eval` / `exec` に外の値を流していないか
- 確かめ方: `a; touch x`、空白を含む名前、`-rf` のような名前を入れて、実際に何が実行されるかを見る

### PY-07 信頼できない入力のデシリアライズ
- 観点: `pickle.load`、`yaml.load` (`safe_load` でないもの)、`marshal`、`eval` に、外から来るデータを渡していないか。`tarfile` / `zipfile` の `extractall` で、`../` や絶対パスを持つ要素が出力先の外に書かないか
- 確かめ方: 読み込むデータの出どころを遡り、外から来るものがあれば、安全な読み込み (`safe_load`、JSON) に替えられるかを見る

### PY-08 ミュータブルなデフォルト引数と共有状態
- 観点: `def f(x, items=[])` や `def f(x, d={})` で、呼び出しをまたいで中身が残らないか。クラス変数のリスト・辞書が、インスタンス間で共有されていないか。モジュール直下の状態が、テストの順序で結果を変えないか
- 確かめ方: 同じ関数を 2 回呼んで、2 回目に 1 回目の値が見えないか。テストを逆順で走らせる

### PY-09 ファイルとリソースの扱い
- 観点: `open()` を `with` なしで使い、例外のときに閉じ忘れないか。`encoding` を指定せず、環境の既定 (Windows の cp932 など) に依存しないか。書き込み途中で落ちたときに、壊れたファイルが残らないか (一時ファイルに書いて `os.replace`)
- 確かめ方: 日本語を含むファイルを、`LANG=C` や別のロケールで読み書きする。書き込みの途中で例外を起こして、元のファイルが残るかを見る

### PY-10 例外の握りつぶし
- 観点: `except:` や `except Exception: pass` が、本来は上に伝えるべき失敗 (入力の誤り、保存の失敗) を黙って飲んでいないか。`KeyboardInterrupt` と `SystemExit` まで捕まえていないか。捕まえた後に、記録も再送出もしていない箇所
- 確かめ方: try ブロックの中で起こりうる例外を挙げ、それぞれが握りつぶされたとき利用者に何が見えるかを書く

### PY-11 SQL の組み立て
- 観点: SQL を f-string、`%`、`+` で組み立てていないか。値はプレースホルダ (`?`、`%s` をドライバに渡す) で渡す。テーブル名・列名など値にできない部分は、許可する名前の一覧と照合しているか
- 確かめ方: 値に `'; DROP TABLE x; --` と `%` を含む文字列を入れて動かす
